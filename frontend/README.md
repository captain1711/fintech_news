# Signalflow — Prospect Pool Intelligence CRM

Signalflow is an intelligence-first CRM platform designed for fintech and BFSI teams to identify high-intent accounts through automated market signal detection.

## Features

- **Prospect-Pool-Centric Intelligence**: Define target markets and strategic "Pain Points" to steer research agents.
- **Execution History**: Track and compare intelligence searches over time with isolated prospect pool runs.
- **Agentic Pipeline**: Uses LangGraph-based agents for news research, signal extraction, enrichment, and account scoring.
- **AI-Powered Outreach**: Automatically drafts personalized email openers based on detected strategic signals.

## Tech Stack

- **Frontend**: React (Vite), Tailwind CSS, TanStack Query, Lucide Icons.
- **Backend**: FastAPI, LangChain, LangGraph.

## Getting Started

1. Start the backend: `python server.py`
2. Start the frontend: `cd frontend && npm run dev`
